<Callout type="warn">
  If you have an older version installed, please
  [uninstall](https://github.com/OpenBangla/OpenBangla-Keyboard/wiki/Uninstalling-OpenBangla-Keyboard)
  it first.
</Callout>

Download the latest version for your platform from [Releases](https://github.com/OpenBangla/OpenBangla-Keyboard/releases).

For detailed installation instructions and platform-specific guides, see the [Installing OpenBangla Keyboard Wiki](https://github.com/OpenBangla/OpenBangla-Keyboard/wiki/Installing-OpenBangla-Keyboard).
