এই পৃষ্ঠাতে ক্ষিপ্র লেআউটে টাইপিং শুরু করার জন্য কয়েকটি মৌলিক উদাহরণ দেওয়া হলো। বিস্তারিত জানার জন্য পরের পৃষ্ঠাগুলো দেখুন।

## পৃথায়ক (`;`) দিয়ে ছিন্নায়ণ

ক্ষিপ্রতে সেমিকোলন `;` হলো পৃথায়ক। পৃথায়ক লেখাকে ছিন্নায়িত বা অংশায়িত করে — পৃথায়কের আগের ও পরের অংশ দুইটি বিচ্ছিন্ন হিসেবে গণ্য হয়।

| ইনপুট   | আউটপুট |
| ------- | ------ |
| `ami;i` | আমিই   |
| `jh`    | ঝ      |
| `j;h`   | জহ     |
| `ae`    | অ্যা   |
| `a;e`   | আএ     |
| `ii`    | ঈ      |
| `i;i`   | ইই     |
| `ka`    | কা     |
| `k;a`   | কআ     |

যুক্তবর্ণ গঠন রোধ করতেও পৃথায়ক ব্যবহার করা যায়। তবে সম্ভাব্য যুক্তবর্ণ না থাকলে পৃথায়ক দেওয়ার দরকার নেই।

| ইনপুট      | আউটপুট |
| ---------- | ------ |
| `budh;bar` | বুধবার |
| `likhte`   | লিখতে  |

একটা শব্দে যতবার ইচ্ছা পৃথায়ক ব্যবহার করা যাবে।

<Callout type="tip">
  শব্দের পরে সেমিকোলন লিখতে হলে দুবার সেমিকোলন চাপতে হবে। যেমন: `ami;;` = আমি;
</Callout>

## স্বরচিহ্ন ও যুক্তবর্ণ গঠন

শব্দের শুরুতে বা স্বরের পরে স্বরবর্ণ, এবং ব্যঞ্জনধ্বনির পরে কারচিহ্ন গঠিত হয়।

| ইনপুট  | আউটপুট |
| ------ | ------ |
| `am`   | আম     |
| `nam`  | নাম    |
| `amar` | আমার   |
| `ka`   | কা     |
| `kk`   | ক্ক    |

## বাংলা অঙ্ক

ইংরেজি অঙ্ক লিখলে সেগুলোই বাংলা অঙ্ক হয়ে যাবে।

| ইনপুট | আউটপুট |
| ----- | ------ |
| `123` | ১২৩    |
| `1.1` | ১.১    |

দশমিক বিন্দু আলাদা করে কিছু করতে হবে না — কোনো অঙ্কের আগে দশমিক বিন্দু অটো বসবে। `.01` = `.০১`।
