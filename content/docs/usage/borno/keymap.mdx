Borno লেআউটের সম্পূর্ণ কী-ম্যাপিং নিচে দেওয়া হলো। প্রতিটি শারীরিক কী থেকে Normal ও Shift — দুইটি লেয়ারে যা আসে তা দেখানো হয়েছে; Borno-তে AltGr লেয়ার নেই।

টাইপ শুরু করার আগে OBK-র Layout Viewer (টুলবারের View বাটন কিংবা ট্রে মেনু থেকে) খুলে কী-ম্যাপিং যাচাই করে নিতে পারেন।

## Grave কী

`` ` `` কী (Esc-র নিচে) — ZWNJ/ZWJ ও বাড়তি চিহ্ন:

| Key     | Normal | Shift |
| :------ | :----- | :---- |
| `` ` `` | ZWNJ   | ZWJ   |

## বিশেষ কী

**ZWNJ/ZWJ:** দুটি পরপর হসন্ত টাইপ করলে Fixed Engine দ্বিতীয় হসন্তকে ZWNJ বানিয়ে দেয়। তাই `উদ্‌দীন` লিখতে:

`H` + `U` + `D` + `H` + `H` + `D` + `Shift+I` + `N`

ক্রমানুসারে: উ → দ → হসন্ত → হসন্ত (দ্বিতীয়টি ZWNJ হয়ে যায়) → দ → ী → ন। তাই `দ্‌দ`-এ যুক্তবর্ণ না করে `দ` আর `দ` আলাদা থাকে।

**Grave কী (`` ` ``):** Normal = ZWNJ, Shift = ZWJ (অফিসিয়াল অভ্র Borno-তে Shift-এ `~` থাকলেও OBK-র Borno-তে সেখানে ZWJ)।

## নাম্বার প্যাড (NumPad)

নাম্বার প্যাডের প্রতিটি কী থেকে যা আসে (`Bengali in NumberPad` চালু থাকলে বাংলা অঙ্ক):

| Key           | Output |
| :------------ | :----- |
| `Num1`        | ১      |
| `Num2`        | ২      |
| `Num3`        | ৩      |
| `Num4`        | ৪      |
| `Num5`        | ৫      |
| `Num6`        | ৬      |
| `Num7`        | ৭      |
| `Num8`        | ৮      |
| `Num9`        | ৯      |
| `Num0`        | ০      |
| `NumAdd`      | +      |
| `NumSubtract` | -      |
| `NumMultiply` | \*     |
| `NumDivide`   | /      |
| `NumDecimal`  | .      |

<Callout type="tip">
  <strong>পরামর্শ:</strong> নাম্বার প্যাড থেকে বাংলা অঙ্ক পেতে `Settings` → `Fixed Layout` →
  `Bengali in NumberPad` চালু রাখুন (ডিফল্টে চালু থাকে)।
</Callout>

<Callout type="info">
  <strong>লক্ষ করুন:</strong> অভ্র কিবোর্ডের অফিসিয়াল Borno লেআউটে `Grave` কীর Shift অবস্থায় `~`
  (টিলডা) আছে। OpenBangla Keyboard-র Borno-তে সেখানে ZWJ বসানো হয়েছে।
</Callout>
