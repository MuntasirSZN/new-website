Avro Easy, Borno, Munir Optima, National (Jatiya), Probhat — এই সব লেআউটই **Fixed Keyboard Layout** ভিত্তিক। অর্থাৎ প্রতিটি শারীরিক কী থেকে নির্দিষ্ট বাংলা বর্ণ আসে; অভ্র ফনেটিকের মতো উচ্চারণভিত্তিক বর্ণান্তর নেই। এই সব লেআউট ব্যবহার করতে হলে কোন কী থেকে কী আসে তা মাথায় রাখতে হয় — ম্যাপিংগুলো প্রতিটি লেআউটের নিজস্ব কী-ম্যাপ পৃষ্ঠায় দেওয়া আছে।

তবে সব fixed লেআউটেই নিচের নিয়ম ও সুবিধাগুলো একভাবে কাজ করে। সেটিংসগুলো OpenBangla Keyboard-এ `Settings` → `Fixed Layout` সেকশনে থাকে।

## কিবোর্ড লেয়ারগুলো

Fixed লেআউটগুলোতে মোট চারটি লেয়ার থাকতে পারে (লেআউটভেদে সবগুলো থাকতে নাও পারে — যেমন Borno-তে AltGr লেয়ার নেই):

| লেয়ার      | কী চাপতে হয়                  | ব্যবহার                                                                      |
| :---------- | :---------------------------- | :--------------------------------------------------------------------------- |
| Normal      | শুধু কীটি                     | লেআউটের সাধারণ বাংলা বর্ণ                                                    |
| Shift       | Shift চেপে কী                 | একই কীর বিকল্প বর্ণ/চিহ্ন — যেমন ড়→ঢ়, ং→ঙ, া→অ, অঙ্কের জায়গায় বিরল চিহ্ন |
| AltGr       | Ctrl+Alt বা Right Alt চেপে কী | স্বরবর্ণের পূর্ণরূপ বা অতিরিক্ত বর্ণ (যদি লেআউটে থাকে)                       |
| Shift+AltGr | Shift+Ctrl+Alt চেপে কী        | AltGr লেয়ারের Shift রূপ — বিরল বর্ণ ও চিহ্ন (লেআউটভেদে)                     |

উদাহরণ (Avro Easy) — `G` কী: Normal = া, Shift = অ, AltGr = আ। তিনটি লেয়ারেই একই কী থেকে তিনটে আলাদা বর্ণ।

## কাজের উদাহরণ: Avro Easy-তে "আমার"

দেখি, লেয়ারগুলো কীভাবে কাজে লাগে:

| ধাপ | কী        | কী হয়  |
| :-- | :-------- | :------ |
| ১   | `AltGr+G` | আ       |
| ২   | `M`       | ম       |
| ৩   | `G`       | া (কার) |
| ৪   | `R`       | র       |

AltGr+G থেকে পূর্ণ আ, তারপর M, তারপর G থেকে া কার (ম + া = মা), শেষে R — মিলে `আমার`। আপনার লেআউটের কী-ম্যাপ পৃষ্ঠায় একইভাবে প্রতিটি কীর চারটি লেয়ার দেখা যাবে।

## টাইপিং স্টাইল: Modern ও Old (Kar Typing Order)

Fixed লেআউটে দুই রকম টাইপিং স্টাইল আছে। `Settings` → `Fixed Layout` → `Kar Typing Order` থেকে `Modern` (ডিফল্ট) কিংবা `Old` বেছে নেওয়া যায়।

**Modern Style Typing (ডিফল্ট):** এই স্টাইলে আপনি ইউনিকোড নিয়মে বাংলা টাইপ করতে পারবেন। কোনো কার (◌া ◌ি ◌ী ◌ু ◌ূ ◌ৃ ◌ে ◌ৈ ◌ো ◌ৌ) সর্বদা ব্যঞ্জনবর্ণ/যুক্তাক্ষরের **পরে** লিখতে হবে। যেমন — "মেডিকেল" শব্দটি লিখতে হবে এভাবে: `ম + ে + ড + ি + ক + ে + ল`। ব্যাপারটি শুরুতে একটু অস্বস্তিকর মনে হতে পারে, কিন্তু উচ্চারণরীতি অনুযায়ী ভাবলে এটি অনেক বেশি সুবিধাজনক।

**Full Old Style Typing:** এই স্টাইলে আপনি পুরাতন আনিস-ভিত্তিক সফটওয়্যারের (যেমন বিজয়) মতো ঠিক সেভাবেই টাইপ করতে পারবেন। যেসব কার ব্যঞ্জনবর্ণের আগে বসে (◌ি ◌ে ◌ৈ) — সেগুলো আগে লিখবেন, যেসব পেছে বসবে (◌া ◌ু ◌ূ ◌ৃ) — সেগুলো পেছে লিখবেন, আর যেসব দুইপাশে বসে (ো ৌ) — সেগুলো আগে-পেছনে আলাদা করে লিখবেন। যেমন — "কোথায়" শব্দটি লিখতে হবে এভাবে: `ে + ক + া + থ + া + য়`। এছাড়া চন্দ্রবিন্দু (◌ঁ) ইত্যাদি ক্ষেত্রেও ইউনিকোডের কার খুঁটিনাটি মাথায় না রেখেই সাধারণ নিয়মে টাইপ করা যায় — আপনার লেখা স্বয়ংক্রিয়ভাবে সাজিয়ে দেওয়া হবে।

## স্বরবর্ণ লেখা (Automatic Vowel Forming)

সবচেয়ে সাধারণ নিয়ম হলো: হসন্ত + কার/মাত্রা মিলে স্বরবর্ণ হয় (এটি Modern স্টাইলে; Old স্টাইলে কার আগে আসে)। যেমন:

| কীস্ট্রোক  | ফলাফল |
| :--------- | :---- |
| হসন্ত + ◌া | আ     |
| হসন্ত + ◌ি | ই     |
| হসন্ত + ◌ী | ঈ     |
| হসন্ত + ◌ু | উ     |
| হসন্ত + ◌ূ | ঊ     |

`Settings` → `Fixed Layout` → `Automatic Vowel Forming` চালু থাকলে (ডিফল্ট; শুধু Modern স্টাইলে প্রযোজ্য) নিচের ক্ষেত্রগুলোতে হসন্ত ছাড়াই সরাসরি স্বরবর্ণ লেখা যায়:

১) কোনো শব্দের শুরুতে — যেমন `এখন`; এই ক্ষেত্রে "এ" লিখতে হসন্ত চাপতে হবে না।

২) কোনো স্বরবর্ণের পরে — যেমন `ওই`; এই ক্ষেত্রে "ই" লিখতে হসন্ত চাপতে হবে না।

৩) কোনো কার/মাত্রার পরে — যেমন `আমরাও`; এই ক্ষেত্রে "ও" লিখতে হসন্ত চাপতে হবে না।

৪) কোনো যাতিচিহ্নের পরে (যেমন `, । ! ? : ; ""`) — যেমন `"এখন"`।

৫) কোনো বন্ধনীর পরে (যেমন `() {[]}`) — যেমন `(এখন)`।

<Callout type="tip">
  <strong>পরামর্শ:</strong> Automatic Vowel Forming চালু থাকলেও সাধারণ নিয়মে (হসন্ত + কার/মাত্রা)
  স্বরবর্ণ লেখা সবসময় যাবে। অর্থাৎ এক পদ্ধতি জানলেই দুটো মেথডে কাজ করা যায়।
</Callout>

## চন্দ্রবিন্দুর অবস্থান (Automatic Chandrabindu Position fix)

ইউনিকোড নিয়মে চন্দ্রবিন্দু (◌ঁ) কার/মাত্রার পরে লেখা হয়। যেমন — "চাঁদ" লিখতে হলে লিখতে হয় `চ + া + ঁ + দ`; চন্দ্রবিন্দু আগে লিখে বাংলা শব্দের মাঝপথে টাইপ করা যায় না।

`Settings` → `Fixed Layout` → `Automatic Chandrabindu Position fix` চালু থাকলে (ডিফল্ট) আপনি কোনো নিয়ম ভেবে টাইপ করতে বাধ্য হবেন না — চন্দ্রবিন্দু (◌ঁ) যেখানেই লিখুন, OpenBangla Keyboard প্রয়োজনমতো সাজালে সেটিকে ঠিক অবস্থানে বসিয়ে দেবে।

## রেফ লেখা (Old Style Reph)

ইউনিকোড নিয়মে রেফ লেখা হয় র + হসন্ত (অর্থাৎ "র্"), আর রেফ যে ব্যঞ্জনবর্ণের ওপর বসবে সেটার **আগে** লিখতে হয়। যেমন — "দর্জি" = `দ + ি + র + ্ + জ + ি`। কিন্তু আমরা সাধারণত ব্যঞ্জনবর্ণ লিখে তার ওপর রেফ বসাতে অভ্যস্ত — এই কারণে `Settings` → `Fixed Layout` → `Old Style Reph` সুবিধাটি আছে। চালু থাকলে (ডিফল্ট; শুধু Modern স্টাইলে প্রযোজ্য) আপনি রেফ ব্যঞ্জনবর্ণের **পরে** লিখলেও OpenBangla Keyboard র + হসন্তকে নিজে ঠিক জায়গায় বসিয়ে নেবে।

উদাহরণ — "দর্জি":

| সুবিধা                       | টাইপ ক্রমে        | ফলাফল |
| :--------------------------- | :---------------- | :---- |
| Old Style Reph চালু (ডিফল্ট) | `দ + ি + জ + রেফ` | দর্জি |
| Old Style Reph বন্ধ          | `দ + ি + রেফ + জ` | দর্জি |

<Callout type="info">
  <strong>লক্ষ করুন:</strong> Full Old Style Typing এ আপনি সবসময়ই রেফ লেখার পুরাতন নিয়ম অনুসরণ
  করবেন — "Old Style Reph" অপশনটি Modern স্টাইলের জন্য।
</Callout>

## র-ফলা, য-ফলা ও ব-ফলা

কোনো ব্যঞ্জনবর্ণ বা যুক্তাক্ষরের পরে র-ফলা বা য-ফলা বসাতে হসন্ত + র / য লিখুন। যেমন — `হ + র্ + দ` লিখলে হয় `হ্রদ`। ব-ফলার ক্ষেত্রে বিশেষ করে বলে রাখা যায়, ব-ফলা ও ব উভয়ই একই কী দিয়ে লেখা যায়; প্রয়োজনে পৃথায়ক ব্যবহার করে বিযুক্ত রাখতে পারবেন।

## হসন্ত, ZWNJ ও ZWJ

Fixed লেআউটগুলোতে জোরপূর্বক যুক্তবর্ণ গঠন করতে চাইলে দুইবার হসন্ত চাপতে হয় — দ্বিতীয়বার হসন্ত চাপলে OpenBangla Keyboard হসন্ত নয়, বরং একটি ZWNJ (শূন্য-প্রস্থ অবিযোজক) বসিয়ে দেয়, যাতে হসন্ত দেখা যায় কিন্তু যুক্তবর্ণ গঠিত হয় না। যেমন — "উদ্দীন" লিখতে হলে `উ + দ + ্ + ্ + দ + ঈ + ন` লিখতে হবে।

এছাড়া OpenBangla Keyboard অনেক ক্ষেত্রে নিজেই ZWNJ/ZWJ বসিয়ে দেয় — যেমন র-এর সাথে হসন্ত/ঊ-কার যোগে কিংবা র‍্য (র + য-ফলা) লেখাতে।

## Traditional Kar Joining

`Settings` → `Fixed Layout` → `Traditional Kar Joining` চালু থাকলে উ-কার, ঊ-কার, ঋ-কারের মতো যুক্তাক্ষর-সৃষ্টিকারী কারগুলোর আগে OpenBangla Keyboard স্বয়ংক্রিয়ভাবে ZWNJ বসিয়ে দেয়। ফলে হ‌ৃদ, র‌ূপ-ধরনের চিরায়ত রীতিতে রূপ পাওয়া যায় (ব্যঞ্জন + কার লিগ্যাচার বন্ধ থাকে)। ডিফল্টভাবে এটি বন্ধ থাকে, অর্থাৎ স্বাভাবিক ইউনিকোড যুক্তাক্ষর/যুক্তাকার লেখা যায়।

<Callout type="tip">
  <strong>পরামর্শ:</strong> এই সুবিধাটি চালু থাকলে অভিধানভিত্তিক বানান সুপারিশগুলোও একই নিয়মে (ZWNJ
  সহ) দেখানো হয়।
</Callout>

## Bengali in NumberPad

`Settings` → `Fixed Layout` → `Bengali in NumberPad` চালু থাকলে (ডিফল্ট) নাম্বার প্যাডের কীগুলো থেকে বাংলা অঙ্ক ০-৯ পাওয়া যাবে; বন্ধ থাকলে ইংরেজি অঙ্ক। প্রতিটি fixed লেআউটের নাম্বার প্যাড ম্যাপিং যথাক্রমে লেআউটের কী-ম্যাপ পৃষ্ঠায় দেওয়া আছে।
