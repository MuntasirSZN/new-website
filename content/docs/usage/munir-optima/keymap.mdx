Munir Optima লেআউটের সম্পূর্ণ কী-ম্যাপিং নিচে দেওয়া হলো। প্রতিটি শারীরিক কী থেকে Normal, Shift, AltGr এবং Shift+AltGr — চারটি লেয়ারে যা আসে তা দেখানো হয়েছে। `—` চিহ্ন বোঝায় সেই লেয়ারে কীটি নিষ্ক্রিয়।

টাইপ শুরু করার আগে OBK-র Layout Viewer (টুলবারের View বাটন কিংবা ট্রে মেনু থেকে) খুলে কী-ম্যাপিং যাচাই করে নিতে পারেন।

## বিশেষ কী

**ZWNJ/ZWJ:** দুটি পরপর হসন্ত টাইপ করলে Fixed Engine দ্বিতীয় হসন্তকে ZWNJ বানিয়ে দেয়। তাই `উদ্‌দীন` লিখতে:

`Shift+;` + `R` + `X` + `X` + `R` + `Shift+L` + `F`

ক্রমানুসারে: উ → দ → হসন্ত → হসন্ত (দ্বিতীয়টি ZWNJ হয়ে যায়) → দ → ী → ন। তাই `দ্‌দ`-এ যুক্তবর্ণ না করে `দ` আর `দ` আলাদা থাকে।

**Grave কী (`` ` ``):** Normal = `৳`, Shift = ZWJ, AltGr = `ৰ`।

## নাম্বার প্যাড (NumPad)

নাম্বার প্যাডের প্রতিটি কী থেকে যা আসে (`Bengali in NumberPad` চালু থাকলে বাংলা অঙ্ক):

| :------------ | :----- |
| `Num1`        | ১      |
| `Num2`        | ২      |
| `Num3`        | ৩      |
| `Num4`        | ৪      |
| `Num5`        | ৫      |
| `Num6`        | ৬      |
| `Num7`        | ৭      |

| `Num9`        | ৯      |
| `Num0`        | ০      |

<Callout type="tip">
  <strong>পরামর্শ:</strong> নাম্বার প্যাড থেকে বাংলা অঙ্ক পেতে `Settings` → `Fixed Layout` →
  `Bengali in NumberPad` চালু রাখুন (ডিফল্টে চালু থাকে)।
</Callout>

<Callout type="warn">
  <strong>সতর্কতা:</strong> Munir Optima-তে Shift+E থেকে U+F0B4 আসে — এটি কোনো বাংলা বর্ণ নয়, বরং
  Symbol ফন্টের একটি PUA (Private Use Area) অক্ষর। কিছু ফন্ট বা অ্যাপে এটি খালি ঘর বা ঠিকমতো না
  দেখানো চিহ্ন হিসেবে ধরাতে পারে।
</Callout>

<Callout type="info">
  <strong>লক্ষ করুন:</strong> Munir Optima-র ডিজিট রো সাধারণ রীতি অনুসরণ করে না — Normal অবস্থায় 1
  থেকে `_`, 2 থেকে `ই`, 3 থেকে `ও` আসে, আর AltGr-এ ৲, ৴, ৵, ৶, ৷, ৸, ৹, ৺-এর মতো বিরল বাংলা
  সংখ্যামূলক অক্ষর পাওয়া যায়।
</Callout>
