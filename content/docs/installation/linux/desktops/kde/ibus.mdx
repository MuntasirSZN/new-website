### Shell কনফিগার ফাইলে environment variable যোগ করুন

কাজ প্রায় শেষ। এবার আপনার `Shell` এর কনফিগার ফাইলে এই তিন লাইন যোগ করে নিতে হবে। অধিকাংশ মানুষ Bash / ZSH ব্যবহার করে, তাদের জন্য যথাক্রমে `~/.bashrc` অথবা `~/.zshrc` ফাইলে এই লাইনগুলো যোগ করতে হবে।

```bash title="~/.bashrc / ~/.zshrc"
# Ibus KDE
export GTK_IM_MODULE=ibus
export QT_IM_MODULE=ibus
export XMODIFIERS=@im=ibus
```

<Callout>
  আমাদের পক্ষে সব `shell` এর config দেওয়া সম্ভব নয়। যারা অন্য shell ব্যবহার করেন, তারা নিজ
  দায়িত্বে এই কমান্ডের সমতুল্য কমান্ড বসিয়ে নেবেন।
</Callout>

<Callout title="Manjaro ব্যবহারকারী">
  আপনি যদি Manjaro ব্যবহারকারী হন, তাহলে `manjaro-asian-input-support-ibus` প্যাকেজটি ইন্সটল করলেই `Shell` কনফিগার হয়ে যাবে:

```bash
git clone https://aur.archlinux.org/manjaro-asian-input-support.git
cd manjaro-asian-input-support
makepkg
pacman -U ibus-input-support-*.pkg.tar.zst
```

</Callout>

</Step>

<Step>

### Logout করে আবার Login করুন

একবার `logout` করে `login` করুন। এখন থেকে OpenBangla Keyboard ব্যবহার করে [টাইপ](/docs/getting-started) করতে পারবেন।

<Callout title="LibreOffice-এ সমস্যা হলে">
  LibreOffice ব্যবহার করতে সমস্যা হলে এই লাইনটি `~/.bashrc` অথবা `~/.zshrc` ফাইলে যোগ করে নিন।

```bash
export OOO_FORCE_DESKTOP="gnome" libreoffice
```

</Callout>

</Step>

<Step>

### IBus-কে default করুন (ঐচ্ছিক)

আপনি যদি `IBus Preferences` কে আপনার সিস্টেমে default input method হিসেবে ব্যবহার করতে চান, তাহলে নিচের লাইনগুলো `~/.config/autostart/ibus-daemon.desktop` ফাইলে যোগ করতে হবে। এতে সিস্টেম reboot দেওয়ার পরও `IBus Preferences` ব্যবহার হবে।

```ini title="~/.config/autostart/ibus-daemon.desktop"
[Desktop Entry]
Type=Application
Exec=ibus-daemon -rxRd
Hidden=false
NoDisplay=false
Name=IBus Daemon
Comment=Start IBus at login
```

</Step>
