---

import { Step, Steps } from "fumadocs-ui/components/steps";
import { Callout } from "fumadocs-ui/components/callout";

<Callout type="warn" title="শুরুর আগে">
  কনফিগার করার আগে অবশ্যই আপনাকে
  [OpenBangla-Keyboard](https://github.com/OpenBangla/OpenBangla-Keyboard) Install করে নিতে হবে।
  Install করার পর একবার logout করে নিতে হবে, তা না করলে Settings এ OpenBangla-Keyboard এর option
  দেখা যাবে না।
</Callout>

<Steps>

<Step>

### Settings খুলুন

প্রথমে সার্চ মেনু থেকে **Settings** খুঁজে বের করে ক্লিক করতে হবে।

![সার্চ মেনুতে Settings](https://preview.ibb.co/cwvKX7/Screenshot_from_2018_04_01_00_20_01_c.png)

ক্লিক করার পর এরকম একটি Screen আসবে। সেখান থেকে আমাদের `Region & Language` Tab এ ক্লিক করতে হবে।

<Callout>
  GNOME 40 বা তার ঊর্ধ্বে ভার্সনগুলোতে `Region & Language` Tab এর পরিবর্তে Settings এর `Keyboard`
  অংশে `Input Source` পাওয়া যাবে।
</Callout>

![Region & Language](https://preview.ibb.co/d8YnkS/Screenshot_from_2018_04_01_00_21_27.png)

</Step>

<Step>

### Input Source যোগ করুন

Input Source এ নিচে একটি প্লাস `+` বাটন থাকবে। সেটিতে ক্লিক করলে `Add an Input Source` নামে একটি মেনু আসবে, যেখান থেকে আমরা **Bangla** সিলেক্ট করব।

![Add an Input Source মেনুতে Bangla](https://image.ibb.co/gFzMC7/Screenshot_from_2018_04_01_00_22_08.png)

</Step>

<Step>

### OpenBangla Keyboard সিলেক্ট করুন

**Bangla** select করার পরপরই অনেকগুলো Option আসবে, যার মধ্য থেকে আমরা **Bengali (OpenBangla Keyboard)** সিলেক্ট করে নিব।

![Bengali (OpenBangla Keyboard) সিলেক্ট করা](https://image.ibb.co/di4ckS/Screenshot_from_2018_04_01_00_22_21.png)

</Step>

</Steps>

ব্যস, হয়ে গেল। এখন আপনি আপনার মনের ইচ্ছা মত বাংলায় [টাইপ](/docs/getting-started) করতে পারবেন।
