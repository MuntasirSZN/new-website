This guide explains how to install OpenBangla Keyboard on Linux using prebuilt packages.

## Installing from a package

You can download a prebuilt package from the [GitHub Releases page](https://github.com/OpenBangla/OpenBangla-Keyboard/releases) and install it manually.

<Steps>
<Step>
### Download the package

Visit the [GitHub Releases page](https://github.com/OpenBangla/OpenBangla-Keyboard/releases) and download the package compatible with your distribution system architecture.

</Step>
<Step>
### Open a terminal in the download directory

Navigate to the directory where you downloaded the package. For example, if it's in your Downloads directory:

```sh
cd ~/Downloads
```

</Step>
<Step>
### Install OpenBangla Keyboard

Choose your distribution below and run the corresponding command.

<Tabs groupId="distro" persist items={["Ubuntu / Debian", "Fedora", "Arch Linux"]}>
<Tab value="Ubuntu / Debian">

```sh
sudo apt install ./OpenBangla-Keyboard_*.deb
```

</Tab>
<Tab value="Fedora">

```sh
sudo dnf install ./OpenBangla-Keyboard_*.rpm
```

</Tab>
<Tab value="Arch Linux">

```sh
sudo pacman -U ./OpenBangla-Keyboard_*.pkg.tar.zst
```

Arch Linux users can also install the package from the AUR:

```sh
paru -S openbangla-keyboard-bin
```

<Callout type="info" title="Note">
You can replace `paru` with `yay` or your preferred AUR helper.
</Callout>
</Tab>
</Tabs>
</Step>
</Steps>

## Other distributions

Check the [GitHub Releases page](https://github.com/OpenBangla/OpenBangla-Keyboard/releases) for a package compatible with your distribution.

If your distribution isn't covered, you can [build OpenBangla Keyboard from source](/docs/installation/linux/build). Alternatively, start a [GitHub discussion](https://github.com/OpenBangla/OpenBangla-Keyboard/discussions) to let us know about your distribution and discuss possible support.

## Finishing up

Once the installation is complete, log out and log back in to make sure the changes take effect.

Follow the [setup instructions](/docs/installation/linux/desktops) to configure OpenBangla Keyboard for your desktop environment.

If you encounter any problems during installation, please [report an issue](https://github.com/OpenBangla/OpenBangla-Keyboard/issues).
