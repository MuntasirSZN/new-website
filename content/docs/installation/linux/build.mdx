This is a step by step build guide for OpenBangla Keyboard for linux.

OpenBangla Keyboard currently has the following build dependencies:

- GCC or Clang
- Rust
- GNU Make or Ninja
- CMake
- Qt 5
- IBus
- Fcitx5
- Zstandard

<Steps>

<Step>

### Install Rust

Install `Rust` using [`rustup`](https://rust-lang.org/tools/install/) by following script.

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

</Step>

<Step>

### Install Dependencies

Install the rest of the dependencies for specific distribution.

<Tabs
  groupId="distro"
  persist
  items={["Ubuntu / Debian", "Fedora", "Arch Linux", "openSUSE", "Solus"]}
>
<Tab value="Ubuntu / Debian">

```sh
sudo apt install build-essential fcitx5 git libibus-1.0-dev libfcitx5core-dev libqt5svg5-dev libzstd-dev qtbase5-dev qtbase5-dev-tools
```

</Tab>
<Tab value="Fedora">

```sh
sudo dnf install cmake fcitx5-devel fcitx5-configtool fcitx5-gtk fcitx5-qt gcc git ibus-devel libzstd-devel make qt5-qtbase-devel qt5-qtsvg-devel
```

</Tab>
<Tab value="Arch Linux">
  
```sh 
sudo pacman -S --needed cmake fcitx5 fcitx5-configtool fcitx5-gtk fcitx5-qt gcc git ibus make qt5-base zstd
```

</Tab>
<Tab value="openSUSE">

```sh
sudo zypper install cmake ibus ibus-devel fcitx5-devel gcc git libQt5Core-devel libQt5Widgets-devel libQt5Network-devel libzstd-devel libzstd1 make
```

</Tab>
<Tab value="Solus">

```sh
sudo eopkg install -c system.devel qt5-base-devel ibus-devel fcitx5-devel zstd-devel git
```

</Tab>
</Tabs>
</Step>

<Step>

### Clone the repository

After installing the required dependencies, clone the repository and change directory.

```sh
git clone --recursive https://github.com/OpenBangla/OpenBangla-Keyboard.git &&
cd OpenBangla-Keyboard
```

</Step>

<Step>
### Switch to the develop branch

Switch to the develop branch and update submodules

```sh
git checkout develop &&
git submodule update
```

</Step>

<Step>

### Build the binaries

In this step generate `cmake` configurations and compile using `cmake`.

<Tabs
  groupId="custom_options"
  persist
  items={["Both", "IBus", "Fcitx"]}
>

<Tab value="Both">

```sh
mkdir build &&
cd build &&
cmake -DENABLE_BOTH=ON -DCMAKE_INSTALL_PREFIX="/usr" ..
```

</Tab>

<Tab value="IBus">
  
```sh
mkdir build &&
cd build &&
cmake -DENABLE_IBUS=ON -DCMAKE_INSTALL_PREFIX="/usr" ..
```

</Tab>

<Tab value="Fcitx">

```sh
mkdir build &&
cd build &&
cmake -DENABLE_FCITX=ON -DCMAKE_INSTALL_PREFIX="/usr" ..
```

</Tab>
</Tabs>

Afterwards, build the binaries inside the `build` directory.

```sh
cmake --build .
```

</Step>

<Step>
### Install to System
From the build directory, just use this command

```sh
sudo cmake --install .
```

</Step>

<Step>

### Logout and Login

The system needs an input method restart. A logout and login back would be the best option.

<Callout title="Warning" type="warn">

Make sure to save your work before logging out, as all running applications will be closed.

</Callout>

</Step>
</Steps>
