This guide explains how to configure Fcitx 5 to use OpenBangla Keyboard on Linux.

## Prerequisites

Before proceeding, make sure you have:

- Fcitx 5 installed on your system.
- OpenBangla Keyboard installed.
- Fcitx 5 selected as your active input method framework.

If you haven't installed Fcitx 5 or OpenBangla Keyboard yet, follow the respective installation instructions first.

## Configure Fcitx 5

### 1. Restart Fcitx 5

After installing OpenBangla Keyboard, restart Fcitx 5 so it can detect the new input method.

You can do this by running:

```bash
fcitx5 -r
```

### 2. Add OpenBangla Keyboard

1. Open **Fcitx 5 Configuration**.
2. Find **OpenBangla Keyboard** in the list of available input methods.
3. Select it and click the arrow button to add it to your active input methods.
4. Click **Apply** to save your changes.

If you can't find OpenBangla Keyboard, make sure it is installed correctly and restart Fcitx 5.

### 3. Switch to OpenBangla Keyboard

Once added, you can switch to OpenBangla Keyboard using the Fcitx 5 input method indicator in your desktop panel.

You can also use the configured keyboard shortcut to switch between input methods.

## Verify the configuration

Open a text editor and try typing in Bangla. If OpenBangla Keyboard is working, you should be able to type Bangla using your configured input method.
