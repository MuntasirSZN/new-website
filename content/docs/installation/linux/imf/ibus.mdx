This guide explains how to configure IBus to use OpenBangla Keyboard on Linux.

## Prerequisites

Before proceeding, make sure you have:

- IBus installed on your system.
- OpenBangla Keyboard installed.
- IBus selected as your active input method framework.

If you haven't installed IBus or OpenBangla Keyboard yet, follow the respective installation instructions first.

## Configure IBus

### 1. Restart IBus

After installing OpenBangla Keyboard, restart IBus so it can detect the new input method.

You can do this by running:

```bash
ibus restart
```

### 2. Add OpenBangla Keyboard

1. Open **IBus Preferences**.
2. Go to the **Input Method** tab.
3. Click **Add**.
4. Find **Bangla** in the language list.
5. Select **OpenBangla Keyboard** and click **Add**.

### 3. Switch to OpenBangla Keyboard

Once added, you can switch to OpenBangla Keyboard using the IBus input method indicator in your desktop panel.

You can also use the configured keyboard shortcut to switch between input methods.

## Verify the configuration

Open a text editor and try typing in Bangla. If OpenBangla Keyboard is working, you should be able to type Bangla using your configured input method.
