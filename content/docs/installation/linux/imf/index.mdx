---
title: Choose an IMF
description: Choose an input method framework for OpenBangla Keyboard.
---

OpenBangla Keyboard needs an input method framework (IMF) to work on Linux. It supports IBus and Fcitx 5. You only need one of them.

Both frameworks work with a wide range of desktop environments, so you can choose whichever suits your needs. However, before installing anything, check whether you already have one installed. If you do, it's generally best to keep using it, as it may already be configured for your desktop environment.

For example, GNOME and Cinnamon typically use IBus by default, so IBus is usually the better choice for those desktops.

KDE Plasma does not come with a particular input method framework by default. Fcitx 5 is a popular choice among KDE users.

If you're using another desktop environment, check its documentation to see whether it recommends a particular input method framework.
