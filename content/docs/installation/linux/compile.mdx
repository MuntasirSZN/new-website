OpenBangla Keyboard currently has the following build dependencies:

- GNU GCC 8 (or later) or Clang 7 (or later) compiler
- Rust 1.34.0 or later
- GNU Make or Ninja
- CMake
- Qt 5.15 or later
- iBus development library
- Zstandard compression library (zstd)

Install them for your distribution:

## Building & Installing

After installing the required dependencies, clone the repository, compile the source code, and install the package on your system:

```sh
# Clone the repository and navigate into the project folder
git clone --recursive https://github.com/OpenBangla/OpenBangla-Keyboard.git
cd OpenBangla-Keyboard

# Create a build directory, compile, and install
mkdir build && cd build
cmake ..
make
sudo make install
```
