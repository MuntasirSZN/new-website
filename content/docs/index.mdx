**OpenBangla Keyboard (OBK)** is an open-source, Unicode-compliant Bangla input method designed for GNU/Linux, macOS, and Windows. It offers advanced automation features and supports popular keyboard layouts.

Because it integrates key features from Avro Keyboard, the transition for existing Avro users is both smooth and intuitive.

## Supported layouts

- Avro Easy
- Avro Phonetic
- Borno
- Khipro
- Munir Optima
- National (Jatiya)
- Probhat
